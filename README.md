# Curva del Faro

Gioco di guida infinito nel browser: strada costiera generata a caso, traffico da scartare, traguardi a tempo, bonus e trappole, classifica top 10 condivisa.

- Gioca: https://cartesio89.github.io/curva-del-faro/
- Classifica: tabella `faro_scores` sul progetto Supabase "calcetto" (lettura e inserimento pubblici, niente modifiche né cancellazioni da fuori).

Comandi: ↑ / W / spazio gas · ↓ / S freno · ← → / A D sterza · P pausa. Su telefono, i pulsanti sullo schermo.
